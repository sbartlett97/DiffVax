The Paper Story (Crystallized)

Working Title: "DiffVax++: Multi-Model, High-Resolution, and JPEG-Robust Image Immunization"

Three contributions, each with a surprising result:

1
H2 — Patch-based 1088px is STRONGER, not just sufficient
Prediction was ≥0.80× baseline. Actual: 1.60×. Mechanism: perturbation accumulation from overlapping patches (~4 patches cover image center at stride=256). Counter-intuitive result with mechanistic explanation.
2
H1 — Multi-model training resists FLUX-based purification
Addresses the "Purify Once, Edit Freely" (arXiv:2603.13028) attack which defeats SD1.5 immunizations by +3-6 dB PSNR. Training against FLUX removes the purifier's ability to recover editability. Results pending H1a checkpoint (~44h)
3
H7 — STE JPEG augmentation enables social media deployment
Instagram (~q=75), Twitter (~q=70) apply JPEG to all uploads, defeating standard immunization. No competitor addresses this. DiffVax (ICLR 2025) evaluates JPEG as counter-attack but doesn't train for it. IDProtector (Dec 2024) explicitly avoids STE. We're first at q=70-75. Gradient flow validated ✓

Infrastructure: Bugs Fixed This Session

FLUX img_ids 3D deprecation
attack_flux.py: removed .unsqueeze(0).expand(batch_size, ...) → passed 2D tensors directly (seq, 3). Diffusers API changed.
FLUX OOM: 94.97 GiB exhausted
12B transformer stores all activations across 4 denoising steps × 57+ blocks for backprop. Fixed: enable_gradient_checkpointing() — recomputes activations, ~8-10× memory reduction at 2× compute cost.
Critical: Training bug — 16 million steps (11 years)
iter_num=10000 epochs × 1600 items = 16M steps × 20s = ~11 years. Fixed: max_steps=8000 added to all configs → 8000 gradient updates × 20s ≈ 44 hours.
SD3Attack CPU offload crash
enable_model_cpu_offload() incompatible with direct pipe.transformer() calls — transformer offloaded to CPU when called. Fixed: removed offload, added gradient checkpointing instead.
H6 eval EDR direction inverted
Was: disrupted = (ssim_edit > ssim_clean - 0.05) [wrong]. Fixed: disrupted = (ssim_edit < ssim_clean - 0.05) — blank output = lower SSIM = disrupted.
H7 JPEG STE gradient flow validated ✓
Forward: output equals JPEG-compressed reference at q=70, q=75. Backward: gradient mean=0.000081 ≈ 1/(1×3×64×64) — confirms identity pass. Probability control 0%/~45%/100% at p=0/0.5/1.0.
