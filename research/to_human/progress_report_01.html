Architecture Gap Analysis

Gap 1: FLUX uses a 16-channel VAE vs SD 1.5's 4-channel VAE
The latent space dimensionality is different, but the pixel-space perturbation produced by DiffVax is architecture-agnostic. The key question is whether FLUX's VAE maps perturbed pixels to latents that disrupt the DiT denoising.
Gap 2: No FLUX attack wrapper existed in the codebase
FIXED   Implemented src/diffvax/attack_flux.py with a differentiable FluxInpaintPipeline forward pass (FlowMatching scheduler, packed latents).
Gap 3: No SD 3.5 attack wrapper
FIXED   Implemented src/diffvax/attack_sd3.py with MM-DiT differentiable forward pass (tri-encoder conditioning).
Gap 4: Loss normalization hardcoded to /512
FIXED   Loss now uses h = img_batch.shape[-2] as the normalization divisor — works at any resolution.
Gap 5: No multi-model training support in train.py
FIXED   Implemented src/diffvax/attack_multi.py (random per-batch model routing) and updated scripts/train.py to call it based on config keys.
Gap 6: 1088×1088 needs either patch inference or retraining
EXPERIMENT READY   Implemented src/diffvax/patch_immunize.py — Gaussian-weighted overlapping patch blending at arbitrary resolution, using existing 512 checkpoint. H2 experiment will quantify effectiveness.
Gap 7: gpt-image-edit is black-box (no gradient)
DESIGN DECISION   Must rely on transfer attacks. Strategy: optimize against open-source models and hope perturbations transfer. This is standard in the adversarial ML literature — we cannot do better without API access for white-box attacks.

Key Architectural Insight

The DiffVax NestedUNet itself requires zero changes to support DiT models and higher resolutions. The architecture is already resolution-agnostic (fully convolutional) and model-agnostic (only sees pixel-space images). What matters is:

  1. Training signal diversity — the UNet++ must see gradients from multiple model families during training to learn universal perturbations.
  2. Resolution-aware loss scaling — fixed (was hardcoded /512).
  3. For inference at 1088px — either patch-based or fine-tuned; the model's convolutional structure means both approaches are viable.

This is a clean research result: the innovation is in the training curriculum, not a new architecture.
