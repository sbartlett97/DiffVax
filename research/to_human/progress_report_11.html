2 critical bugs found and fixed — both would have silently invalidated key experiments

Bug 1 (CRITICAL — H7)

train.py never forwarded jpeg_augment_prob to DiffVaxImmunization

H7 JPEG augmentation would have run with prob=0.0 regardless of what was in the config. The H7 training run would have produced a standard multi-model checkpoint with no JPEG robustness — identical to H1a.

Fix: Added jpeg_augment_prob, jpeg_quality_range, checkpoint_every, stop_file to immunization_config in scripts/train.py.

Bug 2 (CRITICAL — H6)

H6 purification was a literal no-op

The EditorClean purifier used mask=all-zeros. In FluxAttack's denoising loop: latents = latents × mask + image_latents × (1−mask) → with mask=0, resets to original every step. Zero purification for ALL checkpoints.

Fix: Changed empty_mask = zeros → full_mask = ones in purify_with_flux(). EditorClean strategy requires full reconstruction (mask=1 everywhere).

Bug 3 (Config — H1a/H7/H4)

max_steps=8000 stopped training at epoch 5 (3.4h) before convergence. Actual timing: 1.52s/step → epoch 10+ needed.

Fix: max_steps: 16000 in all 3 experiment configs.

Bug 4 (Config — H1a)

self.config never stored in DiffVaxImmunization.__init__. max_steps enforcement was completely broken. H1a ran 26+ uncapped epochs.

Fix: Added self.config = config to __init__.
