Critical Literature Finding — The Purification Attack

arXiv:2603.13028 ("Purify Once, Edit Freely", March 2025): Adversaries can use FLUX.1-fill-dev to purify immunized images, recovering editability with:

  • +3-6 dB PSNR improvement on the purified image
  • -50-70% FID reduction (more natural-looking)
  • This defeats all existing immunization methods (Glaze, PhotoGuard, DiffusionGuard)

Our multi-model training (H1a) directly counters this:

Adversary uses FLUX purifier
↓
Our DiffVax-FLUX immunization
specifically disrupts FLUX
→
Purification fails →
Image still protected

H6 experiment will verify this claim quantitatively.

New Loss Terms (Implementation Details)

H4: VAE Feature-Space Loss

L_total = L_edit + α * L_perturb + β * L_vae_feature L_vae_feature = -||VAE_shared(x+δ).latent_dist.mean - VAE_shared(x).latent_dist.mean||₂² where: - VAE_shared = stabilityai/sd-vae-ft-mse (frozen) - β = 0.5 (configurable via vae_loss_beta in config) - Minimising this (gradient descent) MAXIMISES the latent distance - Forces perturbation to corrupt the VAE-encoded representation - VAE is widely used as base for FLUX, SDXL, SD3.5 → transfer should improve

H7 (Future): Attention Entropy Loss

L_attn = -H(A) where H = Shannon entropy of cross-attention maps Maximising attention entropy distributes model focus uniformly across tokens, preventing the editing model from "finding" the edit region semantically. Captures attention maps via torch forward hooks during the attack forward pass. Motivated by arXiv:2602.14679 (Universal Immunization via Semantic Injection).

Research Contribution Summary

This work makes four concrete contributions:

  1. First benchmark of immunization effectiveness across all three diffusion model families: SD 1.5 (UNet), FLUX (DiT), SD 3.5 (MM-DiT)
  2. Multi-model training curriculum that improves cross-architecture transfer without changing the model architecture
  3. Purification-resistant immunization: the first method that resists FLUX-based de-protection attacks (arXiv:2603.13028)
  4. Resolution-scalable immunization to 1088×1088 via patch-based inference or curriculum fine-tuning — suitable for production social media deployment

Target venues: ICLR 2027 / NeurIPS 2026 (Security track or main track)
